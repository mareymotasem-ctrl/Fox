NEXORA — المرحلة الثانية: الحسابات وأكواد الدعوة

المتطلبات: Node.js إصدار 18 أو أحدث.

1) فك ضغط المشروع.
2) افتح مجلد NEXORA-v2 في Windows.
3) انسخ .env.example إلى ملف جديد اسمه .env (اختياري للنسخة المحلية أدناه).
4) افتح PowerShell داخل المجلد.
5) اضبط مفتاح إعداد المالك في PowerShell قبل أول تشغيل:
   $env:OWNER_SETUP_KEY="اكتب-هنا-مفتاحا-سريا-طويلا-خاصا-بك"
6) شغّل: node server.js
7) افتح: http://localhost:3000
8) اختر «إعداد المالك» وأنشئ حساب sheen بكلمة مرور قوية لا تشاركها.
9) بعد الدخول كمالك، أنشئ أكواد دعوة وأرسل كل كود لصديق واحد.

ملاحظات:
- البيانات تحفظ محلياً في data/db.json.
- الجلسات تنتهي عند إعادة تشغيل الخادم.
- هذه نسخة تطوير محلية؛ لا تفتح المنفذ للإنترنت ولا ترفعها للعامة قبل إعداد HTTPS، وتخزين جلسات دائم، وحماية إضافية وحدود للمحاولات ونسخ احتياطية.
- لا تشارك كلمة مرور المالك أو مفتاح الإعداد.
